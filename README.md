Web-scraping REST API that returns structured JSON from a large catalog of target sites (e-commerce, search engines, social, real estate, finance, and more), with proxies, CAPTCHA, and anti-bot handling managed server-side. Ships an OpenAPI 3.1 contract, official Node/Python/Go SDKs, a CLI, an npm-distributed stdio MCP server (chocodata-mcp), live llms.txt manifests with markdown twins of every docs page, and an ai-plugin.json discovery manifest. Bills only for successful (2xx) responses.

**Areas:** Web Scraping · Data Extraction · SERP · E-Commerce Data · social-media-data · Proxy · MCP · Agent-Native · structured-json
