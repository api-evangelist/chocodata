# Chocodata

Web-scraping REST API that returns structured JSON from a large catalog of target sites (e-commerce, search engines, social, real estate, finance, and more), with proxies, CAPTCHA, and anti-bot handling managed server-side. Offers an npm-distributed MCP server, a live llms.txt docs manifest, and published Claude agent skills.

- **Provider:** https://chocodata.com
- **Documentation:** https://chocodata.com/docs
- **Base URL:** https://api.chocodata.com
- **Tags:** web-scraping, data-extraction, serp, e-commerce-data, social-media-data, proxy, mcp, agent-native, structured-json
- **Public API:** yes
- **Agent-native (MCP / llms.txt / skills):** yes
- **Confidence:** 90/100

## APIs

- **Chocodata Scraper API** — REST API (HTTP + JSON, API-key auth via ?api_key=) returning structured data from a catalog of sites. Endpoints include Product, Search, Universal Web Scraper, and Batch (async). Base host is api.chocodata.com. (`https://api.chocodata.com`)

> REST API confirmed at https://api.chocodata.com with API-key query-param auth (cd_live_/cd_test_). llms.txt confirmed live at https://chocodata.com/docs/llms.txt (also llms-full.txt and per-page .md); the root /llms.txt claimed in the submitted APIs.json was NOT verifiable. OpenAPI at https://chocodata.com/openapi.json and /.well-known/ai-plugin.json are asserted by well-known scans but were NOT independently retrievable — omitted as unverified. The MCP server is LOCAL/stdio only (run via `npx -y @chocodata/mcp-server`, source github.com/Chocodata-com/chocodata-mcp, tools: scrape_product, search_web, batch_scrape, compare_regions, check_credits) with no hosted HTTPS endpoint, so it is not cataloged as an MCP property. Published Claude Skills (amazon-scraper-api-skills, scrape-amazon-product-skill, scrape-amazon-search-results-skill) and a second MCP server belong to the SIBLING product Amazon Scraper API (amazonscraperapi.com) under the same GitHub org — distinct from Chocodata core. SDKs exist for Node, Python, Go, plus a CLI and n8n community node. Vendor's own site reports inconsistent site/endpoint counts (237/598, 470, 383/136).
